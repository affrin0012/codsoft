# Python Mini Projects

This repository contains three beginner-friendly Python projects developed using Python.

## Projects

### 1. Password Generator

#### Description
A Python program that generates a secure and random password based on the length entered by the user.

#### Features
- User-defined password length
- Random password generation
- Uses uppercase letters, lowercase letters, numbers, and special characters

#### Modules Used
- random
- string

---

### 2. Simple Calculator

#### Description
A basic calculator that performs arithmetic operations on two numbers.

#### Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- User-friendly interface

---

### 3. Rock-Paper-Scissors Game

#### Description
A console-based game where the user plays against the computer.

#### Features
- Random computer choice
- Determines the winner
- Displays both choices
- Tracks scores
- Allows multiple rounds

#### Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Tie
